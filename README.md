# Рефлекс — карта съёмок и жилья

Статический сайт: https://naztutnet.github.io/refleks-map/

- `data.json` — исходные съёмочные адреса, смены и сцены; сохранены без изменений.
- `accommodations.json` — предварительные варианты жилья, цены, источники и геопривязка.
- `app.js` — слои, фильтры по типу жилья и датам съёмок, поиск, карточки и копирование.
- `index.html` — адаптивная карта и список.

## Размещение

24 ноября — 25 декабря 2026, 31 ночь, около 45 человек. Приоритет — отдельная комната каждому. По 2–3 человека — запасной вариант после согласования с группой и проверки подходящих спальных мест; распределение пока не согласовано. Транспорт смешанный: общий и самостоятельный. Лимит 1 200 ₽ в сутки, 37 200 ₽ на весь заезд. Для квартир считать только изолированные спальни после проверки планировки.

Цены «от» — опубликованные ориентиры, а не подтверждённые предложения на даты. Месяц не автоматически равен 31 ночи. Наличие, число отдельных комнат, доплаты и возвратный залог требуют отдельного подтверждения. Статусы бюджета: потенциально подходит, нужен расчёт, выше лимита при отдельном размещении.

Категория выбирается по формату предложения: гостиница, апарт-отель, квартира или отдельная студия. Метки по зданиям и комплексам; входы уточняются. Источники и дата проверки находятся в каждой карточке.

## Запуск

```sh
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765. Фильтры сохраняются в адресной строке: `#layer=housing&type=hotel`. Старые ссылки с `#date=02.12` поддерживаются. При недоступности данных жилья съёмочные объекты остаются доступны. Старый ZIP — архив исходной версии; текущая версия находится в корне.
